
# Benny - Discord Bot/Selfbot

It's an educational selfbot/bot to further understand the concepts and core functionalities of C++ when it comes to requests, organization and overall wrapping.
It is also used to learn about CMake and it's various utilities to easily add dependencies across multiple environment.


## Features

- Websocket compression
- Unit tests
